# 📊 Integrated Problems Evaluation Benchmark Data & Reports

This directory stores the programmatic artifacts, synthetic benchmark datasets, tracking videos, and stress-testing evaluation reports generated by [`integrated_problems/notebook.ipynb`](../notebook.ipynb).

---

## 📂 Subdirectories & Artifacts

| Subdirectory / File | Content Type | Description |
| :--- | :--- | :--- |
| **`walls/`** | Image Dataset | Synthetic wall-floor junction benchmark scenes generated across controlled stress sweeps (`dev/` for tuning, `unseen/` for held-out validation) |
| **`videos/`** | Video Data | Generated multi-object line-crossing benchmark videos (`synthetic_crossing.mp4` and tracked overlay `synthetic_crossing_annotated.mp4`) |
| **`text/`** | Image Dataset | Synthesized Persian plate, sign, and document crops under variable lighting and font degradation |
| **`mock_contest/`** | Benchmark Suite | Hidden challenge evaluation set (`set_31337`) used to simulate timed contest conditions |
| **`reports/`** | CSV Reports | Quantitative experimental logs recording algorithm accuracy across parameter sweeps |

---

## 📈 Benchmark Reports (`reports/`)

- **`day35_stress.csv`**: Baseline stress-factor sweep results analyzing wall-angle prediction failure modes under variable blur, shadow, and clutter.
- **`day36_results.csv`**: Comparative benchmark across classical edge/line detection pipelines (Canny + Hough vs. Bilateral + TLS).
- **`day37_stress.csv`**: Final robust pipeline evaluation on multi-factor stress tests with timing logs.
